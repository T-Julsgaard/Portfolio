# Favicon concepts

Generated concept masters for the portfolio favicon exploration.

1. `option-1-ascii-self-portrait.png` — portrait rendered as luminous ASCII/pixel density.
2. `option-2-facet-mask.png` — simplified head assembled from bold white facets.
3. `option-3-tj-glyph-monogram.png` — interlocking `TJ` terminal/stencil monogram.
4. `option-4-portrait-portal.png` — portrait silhouette cut through an assembling glyph grid.

The `previews-32px/` files are downscaled checks for browser-tab legibility. The source files are concept masters; finalize and export the selected direction as `.ico` plus 16/32/48 px PNGs after selection.
