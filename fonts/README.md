# Fonts

ASCII-subset (U+0020–U+007E) TTFs used by the site's UI-font switcher to restyle the
assembled 3D text (see `docs/rendering.md`). Generated with fontTools (variable fonts
instanced at wght 400, then subset, hinting dropped). Regenerate from the upstream
files in the [google/fonts](https://github.com/google/fonts) repo if a face is added.
